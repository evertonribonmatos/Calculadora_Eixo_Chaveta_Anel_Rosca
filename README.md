# 🔧 Calculadora Técnica de Eixo

Calculadora web baseada em normas técnicas para projetos de eixos com chaveta, anel elástico e rosca.

## Normas utilizadas
- DIN 6885 (Chaveta)
- DIN 471 (Anel Elástico)
- ISO 68-1 / ISO 965 (Rosca métrica)

## Como usar

### Opção 1: Rodar localmente
```bash
pip install -r requirements.txt
